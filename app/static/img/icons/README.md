# PWA Icons

This directory should contain the following icon files for PWA support:

- icon-192.png (192x192 pixels) - Used for Android and iOS
- icon-512.png (512x512 pixels) - Used for Android PWA install

You can generate these icons from your logo or create custom icons using:
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/
- https://www.pwabuilder.com/imageGenerator/

For now, the system will use default browser icons until these files are added.
