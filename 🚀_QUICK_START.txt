================================================================================
                        STEP 2: DEPLOY TO RENDER
================================================================================

TIME: 20 minutes
FILE: DEPLOY_QUICK_REFERENCE.md

QUICK STEPS:

1. Go to: https://render.com (sign up with GitHub)

2. Click: "New +" → "Web Service"

3. Connect: Your "elis-stms" repository

4. Configure:
   Name: elis-stms
   Region: Singapore (or closest)
   Branch: main
   Build Command: pip install -r requirements.txt
   Start Command: gunicorn -k eventlet -w 1 --bind 0.0.0.0:$PORT run:app

5. Add Environment Variables (copy from .env.render file):
   - DB_TYPE=postgresql
   - DB_HOST=aws-0-ap-southeast-1.pooler.supabase.com
   - DB_PORT=5432
   - DB_NAME=postgres
   - DB_USER=postgres.qthrznudzkgzrwvygmbd
   - DB_PASSWORD=Elis2026#123
   - FLASK_ENV=production
   - SECRET_KEY=[generate using: python3 -c "import secrets; print(secrets.token_hex(32))"]
   - MAIL_SERVER=smtp.gmail.com
   - MAIL_PORT=587
   - MAIL_USE_TLS=1
   - MAIL_USERNAME=your-email@gmail.com
   - MAIL_PASSWORD=your-gmail-app-password
   - Plus GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET

6. Click: "Create Web Service"

7. Wait: 5-10 minutes for build

8. Get: Your live URL (https://elis-stms.onrender.com)

✅ DONE! App is now live!

================================================================================
                    STEP 3: UPDATE GOOGLE OAUTH
================================================================================

TIME: 5 minutes

QUICK STEPS:

1. Go to: https://console.cloud.google.com

2. Select: Your project → Credentials

3. Click: Your OAuth Client ID

4. Add Authorized redirect URIs:
   https://elis-stms.onrender.com/auth/google/callback

5. Add Authorized JavaScript origins:
   https://elis-stms.onrender.com

6. Save

✅ DONE! Google OAuth now works in production!

================================================================================
                        TROUBLESHOOTING
================================================================================

BUILD FAILED?
→ Check requirements.txt and Python version

DATABASE ERROR?
→ Verify Supabase credentials in Render environment variables

OAUTH ERROR?
→ Check redirect URIs match exactly (no trailing slash)

EMAIL ERROR?
→ Use Gmail App Password (not regular password)

GIT ERROR?
→ Check GITHUB_SETUP.md troubleshooting section
